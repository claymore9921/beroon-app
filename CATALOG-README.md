# Public sales catalog

Public route: `/catalog`

- No login or role authorization is required.
- `1.jpg` is the landing image.
- The fixed `دستگاه‌ها` button opens `2.jpg`.
- `2.jpg` is divided into four equal clickable quadrants:
  - top-right: `s1 -> s2 -> s3`
  - top-left: `h1 -> h2 -> h3`
  - bottom-right: `x91 -> x92 -> x93`
  - bottom-left: `h11 -> h12 -> h13`
- Third-step buttons open `services.jpg` and `about-us.jpg`.
- Images live under `priv/static/images/catalog/`.
